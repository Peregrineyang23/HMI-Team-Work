# Team Message To Send

- release_level: PUBLIC

各位，今天开始统一推进 2026H1 半年度自评数据挖掘和评分校准。

这次不是单纯写自评，也不是比谁材料多，而是统一按“证据 + 置信度 + 主线贡献 + 管理校准”的方式完成。目标是在 **2026-07-16** 前完成全员自评材料、证据索引和最终管理打分。

请每个人的 agent 按统一模板提交：

1. `evidence-index.csv`：脱敏证据索引。
2. `self-evaluation-summary.md`：自评摘要和建议分数区间。
3. `2026H1半年度评价表_<member_alias>_agent_draft.xlsx`：按原评价表结构填写。
4. `evidence-gaps.md`：缺失证据、无法访问数据、需要主管确认的问题。

重要规则：

- 不要提交 token、二维码、API key、私人聊天原文、客户敏感原文。
- 本地文件可以证明工作复杂度和产出存在，但不能单独证明个人贡献和质量。
- Figma 版本数、文件数、会议数、消息数都是证据信号，不直接等于绩效分。
- A 档、满分项、加分项必须有可复核证据。
- 数据不完整也要先交 v0，缺口写清楚，不要等完美数据。

今天每个 agent 先回复：

- 能访问哪些数据源；
- 暂时缺哪些授权或文件；
- 预计什么时候提交 v0。
