李颖的自评数据包有较强的补充价值：它补进了现有团队分析没有覆盖的本地工作流证据，包括 Blender、After Effects、Media Encoder、音频、Agent 脚本、MCP Server 等。与仓库内已完成的飞书/云盘/会议/Figma metadata 分析交叉看，李颖本来就在当前可见云端证据中排名第一，证据分为 101.5，覆盖 AIOS / AI Worker、2026 车展 DEMO、Figma 研究、红旗8397、设计系统 / 动效平台化 5 条线。

但该自评包也有三个需要修正或降置信处理的位置：

1. Excel 最终分为 90，但档位仍填为 B。按照通知页规则，90 分及以上应为 A 档。若管理上希望保守处理，应标成“基础得分 B 档，含加分后 A 档边界”，不能直接写 B。
2. 本地文件证据的路径位于 `/Users/liying/...`，当前审计机器无法访问，因此 Blender / AE / Agent / 音频等只能判定为“有结构化证据说明”，不能判定为“已复核原始文件”。需要导出文件索引或提供可访问快照后再升为高置信。
3. 部分高分项使用了“显著提升”“提效 50% 以上”“跨部门好评”等效果型表达，但证据包没有同步提供用户指标、返工率、外部评价原文或效率前后对比。建议这些项保持 B+/A-，不要完全按 A 档满分处理。

## 五、建议的交叉验证方法

### 1. 原始证据复核

每个自评包必须提供一份 machine-readable evidence index：

| 字段 | 说明 |
| --- | --- |
| evidence_id | 唯一证据 ID |
| person | 成员 |
| project_id | 统一项目 ID |
| source_type | figma / feishu_vc / local_file / jira / wechat_export / script / render |
| path_or_url | 文件路径或 URL |
| created_at / modified_at | 时间 |
| owner / editor / organizer | 责任人 |
| artifact_type | source / export / meeting / comment / task / final_delivery |
| confidence | high / medium / low |
| dedupe_key | 去重 key |
| validation_status | claimed / indexed / sampled / verified |

### 2. 三角校验

每个高分结论至少用两类来源交叉：

| 结论 | 最少验证组合 |
| --- | --- |
| 主责项目 | 自评项目 + 飞书/会议/Jira 主责 + 交付物 |
| 高产出 | Figma/本地源文件 + 最终导出/交付版本 |
| 质量优秀 | 评审通过记录 + 返工次数低 / 客户正反馈 |
| 进度可靠 | Jira/Gantt 状态流转 + 会议/群消息闭环 |
| AI提效 | 工具代码/流程 + 使用记录 + 提效前后对比 |
| 团队贡献 | 分享材料 + 参会/观看/复用记录 + 他人引用 |

### 3. 去重规则

- Figma 版本保存：按文件、作者、时间窗口聚合，避免连续小保存过度放大。
- AE 自动保存：只作为迭代强度，不计为独立项目。
- ME 多码率导出：按同一源项目、同一日期、同一画面内容聚合为一个交付组。
- Blender 多版本渲染：区分探索版本、最终采用版本、模板资产、第三方素材。
- 音频文件：按母版设计、风格、交互类型、最终采用状态聚合，不按导出文件简单相加。
- Agent 代码：按可运行模块、被使用项目、复用范围计分，不按代码行数直接计分。

## 六、半年度绩效计算基础建议

### 建议采用“双分制”

1. evidence_score：客观证据分，用于比较工作量、覆盖面和可追溯性。
2. evaluation_score：绩效评分，按公司评价表的维度和管理判断给分。

二者不要直接等同。证据分回答“留下了多少可追溯贡献”，绩效分回答“这些贡献对业务目标、质量、协作和成长的价值有多高”。

### 建议评分映射

| 档位 | 分数区间 | 必要条件 |
| --- | --- | --- |
| A | 90-100 | 至少 1 条关键项目主责或平台级贡献；证据覆盖 3 类以上来源；质量/交付无重大风险；有跨团队或团队级影响。 |
| B+ | 85-89 | 多项目稳定交付；证据充分；有明确领域优势；但缺少平台级影响、质量指标或加分项。 |
| B | 75-84 | 完成本职和主要项目；证据覆盖正常；协作和质量稳定；创新/影响力有限。 |
| C | 60-74 | 有交付但证据不足、延期/返工较多，或贡献主要为被动执行。 |
| D | <60 | 明显未达成任务、重大质量风险、严重协作问题或证据无法支撑基本交付。 |
